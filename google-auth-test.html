🔐 Athletica — Google Auth Manual Test

Sign in with Google, exchange the ID token at POST /api/v1/auth/google, then call GET /api/v1/auth/me with the Athletica JWT.

Prerequisites

  1. Backend running: npm run dev (default http://localhost:3000).
  2. Serve THIS file from http://localhost (Google rejects file://). From repo root run:
    npx serve . -l 5000 then open http://localhost:5000/google-auth-test.html
  3. Your Google account's email must be new (new-user flow), existing (returning flow), or an email/password account (auto-link flow) depending on what you want to test.

1 — Config

2 — Google sign-in (gives you the ID token)

3 — Exchange with backend
