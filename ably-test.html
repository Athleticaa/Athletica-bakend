Subscribe to conversation:{id} / event message.created and verify a message sent via REST arrives live.

How to test "does realtime work when I send a message?"

  1. Fill API Base URL + JWT + Conversation ID, click Fetch fresh token (tokens expire fast — don't reuse the old pasted one).
  2. Click Connect & Subscribe. Wait for Connection = connected, Channel = attached.
  3. Keep this tab open. In another tab/Postman — or with the Send box below — POST a message to /api/v1/messaging/conversations/{id}/messages.
  4. A green card should appear below within 1–3s. If not, check the log for errors.
